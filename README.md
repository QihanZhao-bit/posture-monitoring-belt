# Sitting Posture Monitoring Belt

## 1. Title

**Sitting Posture Monitoring Belt**

This repository contains the embedded STM32 software for a wearable sitting posture monitoring belt.

---

## 2. Introduction

This project implements the embedded software for a smart wearable belt that monitors sitting posture. The system uses four MPU6050 motion sensors to collect body posture data and sends the processed data to a deployed NanoEdge AI machine learning model.

The software runs on an STM32 microcontroller. It reads sensor data through I2C, calculates posture-related features, classifies the posture as either **Good Posture** or **Bad Posture**, and sends the result through USART2 as Bluetooth output.

## 6. Technical Details
Sensor Reading

The system uses four MPU6050 sensors. Since MPU6050 sensors normally share the same I2C address, a TCA9548A I2C multiplexer is used to select each sensor channel.

For each MPU6050 sensor, the software reads:

accelerometer X, Y, Z data
gyroscope X, Y, Z data

The raw sensor readings are converted into physical values using scale factors defined in the software.

Euler Angle Calculation

The software estimates posture angles using roll, pitch, and yaw.

The accelerometer is used to calculate roll and pitch:

roll = atan2(ay, az)

pitch = -atan2(ax, sqrt(ay^2 + az^2))

The gyroscope data is integrated over time to estimate angular movement. A Kalman filter is used to combine accelerometer-based and gyroscope-based estimates.

NanoEdge AI Input

The final input to the NanoEdge AI model contains 12 values
Sensor 1: roll, pitch, yaw
Sensor 2: roll, pitch, yaw
Sensor 3: roll, pitch, yaw
Sensor 4: roll, pitch, yaw
These 12 values are stored in the input array:float neai_input[12];
The classification function is called as:neai_classification(neai_input, output_class_buffer, &class_id);
The model outputs two possible classes:class_id = 0: Good Posture
class_id = 1: Bad Posture
Design Assumptions
The four MPU6050 sensors are mounted consistently on the wearable belt.
The training data used in NanoEdge AI Studio matches the sensor placement used during real operation.
The Bluetooth module is connected to USART2.
The system performs binary classification only.
## 7. Known Issues and Future Improvements
Known Issues
The system currently supports only two posture classes: Good Posture and Bad Posture.
Yaw angle may drift over time because the MPU6050 does not include a magnetometer.
Classification accuracy depends on sensor placement and training data quality.
The system requires consistent belt positioning during use.
Future Improvements
Add more posture classes, such as leaning left, leaning right, and slouching.
Add vibration or buzzer feedback for bad posture.
Add a mobile application for real-time display.
Add data logging for posture history.
Improve sensor calibration.
Use an IMU with magnetometer support to reduce yaw drift.
