# Sitting Posture Monitoring Belt

## 1. Title

Sitting Posture Monitoring Belt

This repository contains the embedded STM32 software and Android application for a wearable sitting posture monitoring belt.

---

## 2. Introduction

This project implements a smart wearable belt system for sitting posture monitoring. The system uses four MPU6050 motion sensors to collect body posture data. The STM32 microcontroller processes the sensor data and sends the extracted posture features into a deployed NanoEdge AI machine learning model.

The NanoEdge AI model classifies the user's sitting posture into two categories: Good Posture and Bad Posture. The classification result is transmitted through USART2 using a Bluetooth module. An Android mobile application is also included in this repository. The Android app receives the Bluetooth data from the STM32 system, displays the real-time posture classification result, records posture duration, and provides posture history information.

---

## 3. Contextual Overview

The software is part of a wearable posture monitoring system. The overall data flow is:

4 x MPU6050 Sensors  
→ I2C communication through TCA9548A multiplexer  
→ STM32 microcontroller  
→ Sensor data processing  
→ Roll, pitch and yaw calculation  
→ 12 input features  
→ NanoEdge AI machine learning model  
→ Good Posture or Bad Posture classification  
→ USART2 Bluetooth output  
→ Android mobile application  
→ Real-time posture display and posture history

The four MPU6050 sensors are placed on the wearable belt. Their accelerometer and gyroscope data are used to estimate body posture. The STM32 processes the data and sends the classification result through USART2 to a Bluetooth module. The Android application receives this Bluetooth data and displays the posture result to the user.

## 4. Installation Instructions

### Required Software

- STM32CubeMX
- STM32CubeIDE
- NanoEdge AI Studio
- Android Studio

### Required Libraries and Files

The STM32 project requires the NanoEdge AI deployment files generated by NanoEdge AI Studio:

- NanoEdgeAI.h
- libneai.a

The STM32 HAL drivers are generated automatically by STM32CubeMX and included in the STM32CubeIDE project.

The Android application project is included in the repository in the folder:

- Android APP

### Required Hardware

- STM32 development board
- 4 x MPU6050 sensors
- TCA9548A I2C multiplexer
- Bluetooth module connected to USART2
- Android phone
- USB cable
- FPCB
- Power supply

### STM32 Environment Setup

1. Open STM32CubeMX.
2. Configure the required STM32 pins.
3. Enable I2C for communication with the MPU6050 sensors.
4. Enable USART2 for Bluetooth output.
5. Enable USART1 if additional debugging output is required.
6. Generate and open the project in STM32CubeIDE.
7. Add the NanoEdge AI files to the STM32 project.
8. Add the NanoEdge AI include path in the compiler settings.
9. Add the NanoEdge AI static library path in the linker settings.
10. Build the STM32 project.

### Android Environment Setup

1. Open Android Studio.
2. Open the folder named Android APP.
3. Let Android Studio sync the Gradle project.
4. Build the Android project.
5. Connect an Android phone to the computer.
6. Download and install the app onto the Android phone.
7. Enable Bluetooth on the phone and pair it with the Bluetooth module connected to the STM32 board.

## 5. How to Run the Software

### Running the STM32 Program

1. Connect the four MPU6050 sensors to the TCA9548A I2C multiplexer.
2. Connect the TCA9548A multiplexer to the STM32 I2C pins.
3. Connect the Bluetooth module to USART2.
4. Open the STM32 project in STM32CubeIDE.
5. Build the project.
6. Download the program to the STM32 board.
7. Reset the STM32 board.

After startup, the STM32 software initializes the sensors and the NanoEdge AI model. During operation, it continuously sends one of the following classification results through USART2:

- Good Posture
- Bad Posture

### Running the Android Application

1. Open the Android APP folder in Android Studio.
2. Build the Android project.
3. Download the app to an Android phone.
4. Open the app on the phone.
5. Connect the app to the Bluetooth module used by the STM32 system.
6. The app receives the posture classification result sent from USART2 through Bluetooth.
7. The app displays the current posture status in real time.

The Android app can display:

- Current posture classification
- Good Posture duration
- Bad Posture duration
- Good Posture percentage
- Bad Posture percentage
- Recent posture history

If Bad Posture lasts for more than three minutes, the app provides a reminder to the user.

## 6. Technical Details

### Sensor Reading

The system uses four MPU6050 sensors. Since MPU6050 sensors normally share the same I2C address, a TCA9548A I2C multiplexer is used to select each sensor channel.

For each MPU6050 sensor, the software reads:

- Accelerometer X, Y and Z data
- Gyroscope X, Y and Z data

The raw sensor readings are converted into physical values using scale factors defined in the software.

### Euler Angle Calculation

The software estimates posture angles using roll, pitch and yaw.

The accelerometer is used to calculate roll and pitch:

- Roll is calculated from the Y-axis and Z-axis acceleration.
- Pitch is calculated from the X-axis acceleration and the combined Y/Z acceleration magnitude.

The gyroscope data is integrated over time to estimate angular movement. A Kalman filter is used to combine accelerometer-based and gyroscope-based estimates.

### NanoEdge AI Input

The final input to the NanoEdge AI model contains 12 values:

- Sensor 1: roll, pitch, yaw
- Sensor 2: roll, pitch, yaw
- Sensor 3: roll, pitch, yaw
- Sensor 4: roll, pitch, yaw

These 12 values are stored in the NanoEdge AI input array.

The classification model outputs two possible classes:

- Class ID 0: Good Posture
- Class ID 1: Bad Posture

### Output Communication

The classification result is sent from the STM32 through USART2. USART2 is connected to a Bluetooth module, which transmits the result wirelessly to the Android mobile application.

The transmitted messages are:

- Good Posture
- Bad Posture

### Android Application

The Android application is developed using Android Studio. The complete Android Studio project is provided in the Android APP folder.

The app receives Bluetooth data from the STM32 system and displays the posture classification result in real time. It also records the duration of Good Posture and Bad Posture during each wearing session. The history interface shows recent posture records and allows the user to observe posture changes over time.

### Design Assumptions

- The four MPU6050 sensors are mounted consistently on the wearable belt.
- The training data used in NanoEdge AI Studio matches the sensor placement used during real operation.
- The Bluetooth module is connected to USART2.
- The Android phone can pair with and receive data from the Bluetooth module.
- The system performs binary classification only.

## 7. Known Issues and Future Improvements

### Known Issues

- The system currently supports only two posture classes: Good Posture and Bad Posture.
- Yaw angle may drift over time because the MPU6050 does not include a magnetometer.
- Classification accuracy depends on sensor placement and training data quality.
- The system requires consistent belt positioning during use.
- Bluetooth connection stability may depend on the Bluetooth module and Android device.

### Future Improvements

- Improve sensor calibration.
- Use an IMU with magnetometer support to reduce yaw drift.
- Improve Bluetooth connection handling in the Android app.
- Add more posture classes, such as leaning left, leaning right and slouching.
- Add more detailed long-term posture analysis.
